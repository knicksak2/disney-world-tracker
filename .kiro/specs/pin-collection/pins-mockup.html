🛡️ Original-Art Alternatives (launch-safe)
Same feel, same milestones, ownable art. Each of these swaps a specific protected character or landmark for a generic version of the same idea — the enamel-and-metal frame is identical, only the center motif changes.
These are the pins to use if this ever ships publicly. What changed. These are now drawn like real enamel trading pins — die-cut metal silhouettes (Mickey head, castle, crest, star badge, award rosette, coined medallion), recessed colored enamel, a metal-toned rim, and a glossy sheen. The metal itself carries the tier: bronze → silver → gold → iridescent mythic.
  • Shapes signal category. Mickey heads = collection count, castle/crest = park conquest, star badges = interests, medallion/rosette = critic & social, plus mythic iridescent variants for prestige.
  • Everything maps to existing data — experiences, park coverage, facets/interests, ratings, friends, leaderboards, sharing.
  • Locked pins render darkened with a lock and a progress bar toward the goal.
  • Center icons are emoji placeholders — the real feature can swap in custom enamel artwork while keeping this exact metal-and-gloss frame.
