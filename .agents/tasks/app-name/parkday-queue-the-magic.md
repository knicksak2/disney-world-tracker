## Summary answer

| Name | Verdict | One-line reason |
|---|---|---|
| **Parkday** / Park Day | **No-go** | Exact-name app already live (Parkday Inc.), and a second "Parkday" is a Walt Disney World trip planner (parkdayplanning.com, $4.99 iOS) in your exact niche. "Park Day" is also a crowded generic phrase. |
| **Queue the Magic** (also Cue the Magic) | **Caution** | No app uses the name, but a Disney-planning travel agent uses "Queue the Magic" on Pinterest/Linktree/Facebook. Name is 15 chars, queue/cue spelling splits search, and the "Magic ___" slot is crowded. Workable, not distinctive. |

A strong Disney tie is a real benefit, and neither name's problem is "too Disney". The problems are existing users of the same name (Parkday) and weak distinctiveness plus label length (Queue the Magic).

## 1. Parkday: evidence

- **[V] Exact-name app.** iTunes API (US) for `Parkday`, `ParkDay`, `Parkday app`: "Parkday" by Parkday Inc., Food & Drink, 246 ratings, current version 2026-11-13, first released 2020-05-01 (`lookup?id=1502870717`). It is a workplace-lunch delivery app (Crain's NY coverage; Google Play `com.parkday.android`; site heyparkday.com). It is actively maintained and venture-style, so it is not abandoned. Apple generally requires app names to be unique per store [I, from memory, not re-checked], so plain "Parkday" is probably unavailable to you.
- **[V] Same-niche collision.** parkdayplanning.com: "Parkday - Walt Disney World Trip Planner": AI itineraries, Lightning Lane strategy, wait-time tips, day-by-day planning, share with group, $4.99 one-time on iPhone, with a Disney non-affiliation disclaimer. I did not find it in the US iTunes API under `Parkday`, `Parkday Disney`, or `Parkday Walt Disney World Trip Planner`, so its release status is unverified. A GitHub project `Plebcy/parkday` ("unofficial Walt Disney World trip companion", live waits via ThemeParks.wiki) uses the same name too.
- **[V] "Park Day" phrase is crowded in Travel.** `Park Day` / `Park Days` hits: Orlando Theme Park Day (InsiderGuide.com, 856 ratings, Travel), SoCal Theme Park Day (20), My Theme Park Day (1), MyParkDay (0), One Perfect Park Day (0), ParkPulse: Your Park Day (0, already rejected), PARK DAY_OSAKA (0, Lifestyle).
- **[V] Domains all taken:** parkday.com, .app, .co, .io, parkdayapp.com, getparkday.com all resolve or have NS records (details in section 5).
- **Disney tie:** [I] "Park day" is loose fan vocabulary, not a Disney mark, so no 5.2 problem. The tie is mild, which is also why the phrase is generic and hard to own.
- **Trademark:** [not verified] USPTO cannot be queried here. Parkday Inc. likely holds or claims rights in food/delivery classes [I]. Different class lowers legal conflict but not App Store name or search collision.

## 2. Queue the Magic / Cue the Magic: evidence

- **[V] App Store (US):** `Queue the Magic`, `QueueTheMagic`, `Queue the Magic Disney`, `Cue the Magic`, `CueTheMagic`, `Cue the Magic app`: zero apps with either name. Nearest: "On Queue: Theme Park Waits" (Bradley James Troll, Travel, 0 ratings, updated 2026-07-31) and "Queue Kingdom" (Brent Workinger, Travel, 1 rating, WDW/Disneyland waits). So the queue pun is already used twice in the waits niche.
- **[V] Same-niche brand:** Pinterest `QueueTheMagic` ("help you plan your next Disney vacation") and Linktree `queue.the.magic` (Rachel Poindexter Ngeam, "Simple Magic" Facebook planning group). Reads as a small Disney travel planner. Related services (Disney vacation planning vs a planning app), so a cease-and-desist is unlikely but not impossible [I].
- **[V] Usage as a phrase:** Catch Us At The Castle podcast episode titled "Queue the Magic: Beating the Lines at Disney World!" (iHeart, Oct 2025). That is an episode title, not a brand, but it shows fans already use the pun about lines.
- **[V] Cue the Magic elsewhere:** "Cue The Magic: Sing a New Song" podcast (music therapy), "Cue the Magic Events" (corporate events, Squarespace), a 2012 WDWMagic forum thread title. None are Disney-owned.
- **[V] Disney's phrasing:** Disney's own campaigns surfaced in search are "This Is Magic" and "Make the Holidays Magic". I found no evidence Disney uses or registered "Cue/Queue the Magic" [not exhaustive; USPTO unchecked].
- **[V] Crowded "Magic ___" slot on the App Store:** Magic Guide(R), MagicDay, MagicWait for Disney World, MagicFlw, MyMagicTrip, Thrill Data "Wait Magic", Mouse Times. "Magic" is one of the most-used words in this category.
- **[V] Domains:** queuethemagic.com is parked (dns-parking), .app/.co/.io show no DNS; cuethemagic.com is registered (DreamHost, no A record), cuethemagic.app has no DNS.
- **Fit:** 15 chars, so iOS home-screen label shows roughly "Queue the Ma..." [I, ~11-12 chars]. Pun works in print, but spoken "cue the magic" cannot signal "queue", and users will search either spelling. It describes the idea (lines/waits) but not trip crew, pins, food or expenses. Tone is friendly and fan-like.
- **Disney tie / Apple 5.2:** [I, guideline numbers from memory] "Magic" and "queue" are ordinary words; Disney-owned terms to avoid are Disney, Mickey, Magic Kingdom, Genie/Genie+, Lightning Lane, MagicBand, MagicMobile, Magic Key. The name uses none of them, so it reads as fan vocabulary. A strong tie helps recognition; the risk to manage is looking official, handled by non-affiliation text in the listing and no Disney art.

## 7. Recommendation

- Drop **Parkday**: even with a different category, the same-niche planner and the live exact-name app make it a weak foundation.
- Keep **Queue the Magic** only if you value the Disney-fan pun over label length; if you do, register the .app/.com now, register both spellings, and plan for a truncated home-screen label (set a short display name such as "Queue Magic" [I, not screened]).
- If neither wins, screen **Park Daybook** or **Queue Ears** further before choosing; otherwise return to the earlier finalists.
- Before any public release: a real USPTO search for the chosen name and a Disney non-affiliation line in the listing.
