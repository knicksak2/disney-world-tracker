How to use this. Each entry is intentionally simplified — sample/placeholder data, no live queries, no gestures — the goal is layout + content inventory, not fidelity. 47 screens across Auth, Home, Catalog, Trips, Friends, Profile, Stats, and Food. Screens nested under a tab keep the tab bar + a header back arrow (tabsBack); truly root-level pushes (ExperienceDetail, Menu, the three root food screens) hide the tab bar entirely, matching how they're actually registered in RootNavigator.tsx today. Modals render as a bottom sheet over a dimmed scrim. This file makes no code changes and is not wired to the real API.
